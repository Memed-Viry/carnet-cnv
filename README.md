# Carnet du Club · CN Viry-Châtillon Maîtres

Application web installable (PWA) des nageurs Maîtres du CN Viry-Châtillon : temps extraNat, analyses de course, relais, Interclubs, calendrier, séances personnalisées.

Ouvrir sur le téléphone : https://memed-viry.github.io/carnet-cnv/ puis « Sur l'écran d'accueil » (iPhone, Safari) ou « Installer l'application » (Android, Chrome).

Données : performances publiques extraNat (FFN), mises à jour chaque semaine.
